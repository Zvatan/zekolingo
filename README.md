# Zekolingo

Konu konu İngilizce öğrenme uygulaması (A1–B1): Türkçe konu anlatımları, açıklamalı alıştırmalar, kur sınavları, hata defteri, kelime kartları ve okuma metinleri.

Bu depo yalnızca yayınlanan dosyaları içerir. Kaynak ve içerik araçları yerel `Zekolingo` klasöründe tutulur. Güncellemek için orada `node tools/build.mjs` çalıştırılır ve `dist/` içeriği bu depoya kopyalanır.

iPhone'da kullanmak için siteyi Safari ile açın → Paylaş → Ana Ekrana Ekle.
